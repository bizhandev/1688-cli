# Поиск фабрик по фото

`1688 source-photo` принимает ссылку на изображение или локальный файл. Исходную выдачу открывает команда `image-search`. Подборщик сравнивает изображения вариантов, проверяет описание и условия заказа в карточках 1688. Для результата выбирает до трёх разных производителей. Причина для признака «производитель» сохраняется в поле `factory_evidence`.

Нужны Node.js 20 или новее, Python 3.11 или новее и совместимый с Playwright Firefox. Для OCR используются локальные языковые файлы.

```powershell
pnpm install --frozen-lockfile
pnpm build
npm ci --prefix sourcing
python -m pip install -r sourcing/requirements-visual.txt
python sourcing/visual_rank.py --setup
node dist/cli.js source-photo .\photo.webp --title "Описание товара" --output result.json
```

Установленный совместимый Firefox выбирается через `BB1688_FIREFOX_EXECUTABLE`, его профиль через `BB1688_FIREFOX_PROFILE_DIR`. Для установленного в стандартном месте Camoufox на Windows есть локальные значения по умолчанию. При проверке 1688 скрипт выводит окно на передний план и ждёт пользователя до 15 минут. После подтверждения он продолжает работу в той же сессии. Флаг `--headless` возвращает статус прерывания при необходимости ручной проверки.

## Сходство и цена

К концу пакетного запуска некоторые фабрики встречаются в выдаче сразу нескольких фотографий. Скрипт повторно сравнивает уже сохранённые снимки вариантов с каждой исходной фотографией, если за время работы появились новые сведения об объявлениях из её выдачи. Для этой сверки достаточно локальных данных.

Скрипт сравнивает фотографии первой страницы выдачи, до 60 карточек. Для тюбинга название и фото помогают исключить предметы другой категории. Сначала он оценивает варианты уже прочитанных карточек из этой же выдачи, если им меньше суток. Затем открывает новых претендентов на первую тройку и пересчитывает места после просмотра их вариантов. По умолчанию список дополнительной проверки ограничен 12 объявлениями. При `--details 60` скрипт проверяет все подходящие объявления первой страницы.

`match_confidence_pct` оценивает конкретный вариант SKU. Модель DINOv2 сравнивает общий вид, SIFT проверяет совпадение деталей рисунка в разных точках фотографий. Высокое сходство общего вида даёт до 80 баллов. Совпадение рисунка с подтверждённой геометрией допускает более высокую оценку. Совпадение всего кадра даёт до 99. Одинаковая фотография у нескольких неоднозначных SKU, неизвестный размер и неподтверждённая комплектация ограничивают оценку. При отсутствии пригодного изображения процент вычислить нельзя. Шкала эвристическая. Её вероятностная калибровка потребует размеченных пар для каждой категории.

Объявления с явным конфликтом размера, модели, цвета или комплектации исключаются. В пределах трёх пунктов уверенности скрипт сравнивает оборот или количество проданных товаров всей фабрики за одинаковый период. Если этих показателей ещё нет, скрипт открывает профили претендентов на первую тройку при оценке лидера группы от 50 баллов. При отсутствии сопоставимых данных сохраняется ранжирование по сходству. Число продаж отдельного объявления относится только к этому объявлению.

`unit_price_cny`, `min_order` и `lot_price_cny` относятся к выбранному SKU и первой применимой ценовой ступени. Сумма партии равна цене за единицу, умноженной на минимальное количество. Доставка в неё не входит. Оптовые цены других вариантов, рекламные цены и цены аксессуаров требуют отдельной проверки.

## Google Sheets

Вне репозитория создайте `sheet-config.json` и укажите путь в `BB1688_SHEET_CONFIG`. В нём нужны `spreadsheetId` и числовой `sheetId`. Учётные данные берутся из `GOOGLE_APPLICATION_CREDENTIALS`, из `auth.file` или из переменной, указанной в `auth.variable` и файле `auth.dotenv`. Права редактора нужны только для записи в выбранную книгу. Рабочие данные, отчёты и контрольные копии записанных ячеек лежат в каталоге `sourcing` внутри `BB1688_HOME`.

```powershell
node dist/cli.js source-photo --rows 10:19 --output preview.json
node dist/cli.js source-photo --rows 10:19 --write --output saved.json
```

Столбцы B, D и E задают фото, название и артикул. В T каждая ссылка показывает уверенность модели. Примечание раскрывает вариант, фабрику и признаки, которые ещё требуют сверки. Примечание U перечисляет цену за единицу, количество и стоимость партии для каждого предложения с подтверждённой ценой. Число в U попадает в формулы листа, поэтому оно заполняется только для подтверждённого первого варианта с ценой за штуку. Существующие ручные значения и формулы сохраняются. Исполнитель сверяет входные данные перед записью и значения после неё. Для продолжения прерванной серии повторите ту же команду.
